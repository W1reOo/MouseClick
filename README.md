# MouseClick — 鼠标左键自动连点器

一个轻量、免安装、零第三方运行时依赖的 Windows 鼠标左键自动连点工具。支持自定义点击间隔、一键启动/停止、无限循环或指定次数，并已打包为可独立运行的单文件程序。

## 直接下载使用

到 [Releases](../../releases) 下载 `AutoClicker.exe`，双击即可运行（也可直接使用仓库内的 `dist/AutoClicker.exe`）。
首次运行若被 SmartScreen 拦截，点击「更多信息 → 仍要运行」。

## 功能特性

- **自定义间隔**：数值 + 单位（毫秒 / 秒），如 `100 毫秒 ≈ 10 次/秒`
- **次数模式**：无限循环，或指定次数后自动停止
- **点击位置**：当前光标位置，或固定坐标（内置 3 秒倒计时「拾取」按钮）
- **全局热键**：默认 `F6`，窗口不在焦点时也生效，一键启动 / 停止
- **启动倒计时**：留出时间把鼠标移到目标窗口
- **按下保持**：可设置按下与抬起的间隔，适配要求较高按下时长的软件
- **窗口置顶 / 配置自动保存**：关闭后下次打开自动恢复上次设置

## 快速上手

1. 设置「点击间隔」，例如 `100` + `毫秒`
2. 选择「无限循环」或填写「指定次数」
3. 需要定点点击时，选择「固定坐标」并点「拾取」记录位置
4. 设置「启动倒计时」（建议 3 秒），点击「启 动」
5. 再次点击「停 止」或按 `F6` 立即停止

详细说明见 [使用说明.md](使用说明.md)。

## 从源码打包

```bat
:: 安装打包工具
py -m pip install -r requirements.txt

:: 一键打包，产物位于 dist/AutoClicker.exe
build.bat
```

等效命令：

```bat
py -m PyInstaller --noconsole --onefile --clean --name AutoClicker auto_clicker.py
```

## 目录结构

```
auto_clicker.py      主程序源码（tkinter 界面 + ctypes 调用 Win32 API）
build.bat            一键打包脚本
requirements.txt     打包依赖（仅 pyinstaller）
使用说明.md           详细使用说明
dist/AutoClicker.exe 打包产物，可独立运行
```

## 实现说明

| 模块 | 做法 |
| --- | --- |
| 界面 | `tkinter`（Python 标准库） |
| 模拟点击 | `ctypes` 调用 Win32 `mouse_event` 发送左键按下 / 抬起 |
| 全局热键 | 后台线程轮询 `GetAsyncKeyState`，无需管理员权限 |
| 定时 | 基于 `time.perf_counter()` 累计补偿，避免长时运行间隔漂移 |
| 并发 | 连点在独立线程执行，`threading.Event` 分段等待保证停止即时响应、界面不卡死 |

## 注意

- 部分带反作弊或底层输入检测的游戏 / 软件可能不响应模拟点击。
- 请遵守相关软件与游戏的用户协议，勿用于违规或影响他人的场景。
